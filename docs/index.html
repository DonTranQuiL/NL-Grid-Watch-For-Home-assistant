Dutch grid stress forecast

Backfeed by day.
Evening peak by night.

A Home Assistant integration that turns a Dutch postcode into a local overload forecast from the capaciteitskaart and Open-Meteo weather — not a cable-fault promise.

Install with HACS Latest release

What it forecasts

Two directions on the same street cable. High risk means windows like this are when areas like yours get inverter trips or local overload.

Backfeed

Teruglevering already tight, and the next midday is clear. Typical result is an inverter trip; a real outage is the failure case.

Evening peak

Afname already tight, and the coming evening is dark and cold. The 16:00–21:00 window: cooking, heat pumps, EV chargers.

Last-good data

A failed poll keeps the last snapshot on screen. Optional energieonderbrekingen interruptions when you have a token.

Entities you get

Status sensors for afname and teruglevering, risk levels with windows in the attributes, and a binary sensor that flips when either risk is high.

Installation

HACS custom repository, then a restart.

HACS

  1. 1. HACS, Integrations, then the menu, Custom repositories.
  2. 2. URL https://github.com/DonTranQuiL/NL-Grid-Watch-For-Home-assistant
  3. 3. Category Integration, then Add.
  4. 4. Download NL Grid Watch and restart Home Assistant.
  5. 5. Settings, Devices and services, Add integration, NL Grid Watch, enter your postcode.

Blueprint

Import blueprints/automation/grid_stress_notify.yaml to get a ready-made notification when stress is expected.

Service nl_grid_watch.refresh forces an immediate poll.
